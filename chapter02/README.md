# Chapter02. VPC 구성

# VPC(Virtual Private Cloud) 란?
VPC는 AWS 클라우드 내 논리적으로 격리된 가상 네트워크입니다. 사용자가 정의한 가상 네트워크에서 AWS 리소스를 시작할 수 있으며, IP 주소 범위 선택, 서브넷 생성, 라우팅 테이블 및 네트워크 게이트웨이 구성 등 네트워크 환경을 완벽하게 제어할 수 있습니다.

# EKS에서 VPC의 역할
EKS 클러스터에서 VPC는 다음과 같은 중요한 역할을 합니다.
1. 컨테이너 네트워킹 기반 : 파드(Pod)와 서비스가 통신하는 기본 네트워크 인프라 제공
2. 보안 경계 : 클러스터 리소스를 외부 위협으로부터 보호하는 격리 환경
3. 트래픽 제어 : 내부/외부 트래픽 흐름을 세밀하게 제어
4. 리소스 연결 : 데이터베이스, 캐시 등 다른 AWS 서비스와의 연결 지원

# EKS를 위한 VPC 생성 시 주의사항
1. 서브넷 구성
- 최소 요구사항 : 서로 다른 가용 영역에 최소 2개의 서브넷 필요
- 권장 구성 : 퍼블릭 서브넷 2개, 프라이빗 서브넷 2개(최소)
- CIDR 블록 : 충분한 IP 주소 공간 확보 (최소 /24, 권장 /16~/20)
- 가용 영역 : 리전 내 최소 2개 이상의 가용 영역에 분산 배치
